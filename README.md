# Siberian Skazy

Сборник авторских сибирских сказок и историй.

## О проекте

Здесь собраны мои оригинальные сказки, вдохновлённые сибирской природой, культурой и фольклором. А также просто детские сказки и истории. Тексты можно читать прямо в репозитории — каждая сказка хранится в отдельном файле.

## Как читать

- Откройте папку с текстами `stories/`.
- Каждый файл — отдельная сказка или история.
- Файлы в формате Markdown (`.md`) — их удобно читать прямо на GitHub.
